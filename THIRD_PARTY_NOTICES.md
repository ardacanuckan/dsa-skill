# Third-party notices

## Archify

This package is a fork of **Archify** (`tt-a1i/archify`), MIT licensed. Archify is
itself derived from **Cocoon-AI/architecture-diagram-generator**, also MIT licensed.
The JSON IR, the five renderers, the geometry solver, the workflow compiler, the
validator and the artifact checker come from that lineage. The upstream licence text is
kept verbatim in `LICENSE.archify`.

## Fonts

The delivered HTML embeds the latin subsets of four open-source typefaces as base64
`@font-face` rules so the artifact renders identically offline. All four are under the
SIL Open Font License 1.1.

| Font | Role | Source |
|---|---|---|
| Shantell Sans | diagram text | [Google Fonts](https://fonts.google.com/specimen/Shantell+Sans) |
| Inter | page chrome | [Google Fonts](https://fonts.google.com/specimen/Inter) |
| IBM Plex Mono | tags, paths, hostnames | [Google Fonts](https://fonts.google.com/specimen/IBM+Plex+Mono) |
| IBM Plex Serif | available to authored copy | [Google Fonts](https://fonts.google.com/specimen/IBM+Plex+Serif) |

## Colours

The palette is tldraw's twelve default shape colours, used as colour values. tldraw is
a separate project and is neither bundled nor endorsed here.
